How this works, and what it doesn't cover yet

  • Forced-pick question: "If you had to pick one email client for a busy professional, Superhuman or {rival}?" Asked in both name orders, 5 fresh runs each (60 answers total), via the OpenAI API (gpt-4o) directly rather than the ChatGPT web app, with a system prompt forcing a decisive pick.
  • Open comparison question: "Superhuman vs. {rival}: which should I choose?" Asked once per order (12 answers), no system prompt — this is where the qualitative reasoning below comes from. It is not repeated, so a single odd answer could be noise. The API route has no browsing, so none of these answers carry citations — they're the model's general knowledge, not a sourced comparison.
  • Both orders are asked because the model can lean toward whichever brand is named first. For Shortwave, Hey, Front, Missive and Mailbird it barely matters — Superhuman wins 8 or 10 of 10 either way. Spark Mail is the one real exception: Superhuman wins only 2 of 5 when named first, but 4 of 5 when Spark Mail is named first instead — a genuine, order-sensitive close contest, not a clean win.
  • The headline finding: Superhuman wins cleanly almost everywhere, but Spark Mail is a real rival on the model's own telling — genuine cross-platform support (iOS, Android, macOS, Windows) against Superhuman's macOS/iOS-only reach, a working free tier, and a smart auto-categorized inbox the model calls out specifically.
  • Not yet covered: pricing, integrations, onboarding, setup and support as separate scored dimensions — they'd need their own repeated, structured prompts to be real rather than invented. Also not covered: any run through the ChatGPT web app, and any run while logged in.
